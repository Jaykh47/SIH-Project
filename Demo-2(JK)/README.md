# LandStack Stage 3

A frontend GIS/land-record architecture prototype.

## What is demonstrated
- City selection and map focusing
- Mock cadastral parcel layer
- Unique Parcel IDs linked to record objects
- Parcel list synchronized with map
- Land-use/status filters
- Parcel detail view
- Data provenance/source field
- Linked-record placeholders

## Intended production architecture
Frontend: Leaflet/React
API: REST/JSON
Spatial database: PostgreSQL + PostGIS
Geometry exchange: GeoJSON
Geocoding: production geocoding provider
Authoritative data: cadastral/government GIS sources

## Important
The included polygons and land records are demonstration data only.
