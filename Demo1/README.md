# Bharat LandStack Demo

A front-end prototype for the problem statement:
**An Integrated GIS-based Digital Public Infrastructure for Land Governance**

## Features
- Parcel-centric GIS visualization using Leaflet + OpenStreetMap
- Demo ULPIN-based parcel search
- Linked RoR, registration, planning, encumbrance, tax and utility data
- Toggleable zoning, utility and restriction layers
- Citizen service portal
- Ownership verification demo
- Transaction/workflow tracking
- Administrative dashboards
- Department integration health
- Governance alerts and parcel analytics
- Audit trail and illustrative API events
- Responsive layout

## How to run
Open `index.html` in a browser.

For best behavior, run with a local server:
- VS Code Live Server, or
- Python: `python -m http.server 8000`

Then open `http://localhost:8000`

Note: The base map needs internet because it uses OpenStreetMap tiles and Leaflet CDN.
All parcel/land governance information in this prototype is demo/mock data only.
